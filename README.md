## Abstract

Employee attrition is a major challenge faced by organizations, resulting in
increased recruitment costs, productivity loss, and difficulties in retaining
skilled employees.

Traditional machine learning models can predict whether an employee is likely
to leave an organization, but they often do not clearly explain why the
prediction was made.

This project proposes an Explainable AI Framework for Employee Attrition
Prediction. The system uses machine learning models such as Random Forest,
XGBoost, and Logistic Regression to predict employee attrition.

Explainable AI techniques such as SHAP and LIME are used to identify the major
factors contributing to each prediction. The system can also provide
department-level insights to support employee retention and HR decision-making.
